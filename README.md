# PWA Manager

Professional PWA and desktop application manager for Linux environments.

PWA Manager helps manage Progressive Web Apps, Chrome PWAs and desktop applications through a simple command-line interface.

## Features

- Detect installed PWAs and desktop applications.
- Check application health.
- Validate desktop entries.
- Manage application icons.
- Create backups.
- Restore previous states.
- Export portable configurations.
- Detect duplicate desktop entries.

## Supported Applications

PWA Manager supports:

- Managed PWAs.
- Chrome PWAs.
- Linux desktop applications.
- AppImage applications.
